# Tripleten web_project_around_es

En este proyecto se ha trabajado con un conjunto de funciones, elementos y objetos con el propósito de trabajar en una página web tipo red social, donde se interactúa con botones, se manipula información de tipo input.

He reforzado conocimientos sobre cómo declarar funciones, trabajar con manipulación de elementos de un formulario, cómo hacer que los botones tengan vida y sean dinámicos.

Todavía falta la tercera parte del proyecto, pero todo va marchando bien.
